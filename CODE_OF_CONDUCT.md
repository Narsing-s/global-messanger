# Code of Conduct

## Our commitment

Global Messenger is an open-source project intended to be welcoming to people with different backgrounds, experience levels and perspectives.

We are committed to providing a respectful environment for contributors, maintainers, testers and users.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while discussing technical disagreements.
- Give actionable feedback about code and ideas.
- Welcome beginners and help them find a reasonable first contribution.
- Respect privacy and never publish another person's private information.
- Keep discussions focused on improving the project.

## Unacceptable behavior

- Harassment, discrimination or personal attacks.
- Threats or intimidation.
- Publishing private or sensitive information without permission.
- Trolling, deliberate disruption or repeated bad-faith behavior.
- Sexualized or otherwise inappropriate behavior toward community members.

## Maintainer responsibility

Maintainers may remove comments, close discussions, reject contributions or restrict participation when behavior violates this Code of Conduct or harms the project community.

## Reporting

For security vulnerabilities, follow [`docs/SECURITY.md`](./docs/SECURITY.md) rather than posting sensitive exploit details publicly.

For ordinary project issues, use GitHub Issues and provide reproducible technical information without passwords, tokens or private user data.

## Scope

This Code of Conduct applies to project spaces and interactions conducted on behalf of the Global Messenger community, including Issues, Pull Requests and project discussions.

Thank you for helping keep the Global Messenger community welcoming and productive.
