Updates

The Android build workflow publishes the newest successful main-branch APK to the maintained android-latest release. This means the Android download on this page is refreshed automatically after each successful Android build.

Languages

Global Messenger is Unicode-ready. Users can type and send messages in their own regional language using the keyboard already provided by Android, iPhone/iPad, Windows or Mac. We do not need to ship a separate keyboard for every language. The app should preserve Unicode text exactly and can add in-app translation/transliteration later as an optional feature.

Global Messenger is designed to be accessible worldwide. Platform installation methods differ, but the web version remains available to everyone with a supported browser and internet connection.
