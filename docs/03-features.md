# Features

## Messaging

- Direct conversations
- Group conversations
- Realtime delivery
- Typing indicator
- Emoji picker
- Reactions
- Replies
- File/image sharing
- Message edit window: one hour
- Delete for everyone window: one hour
- Delete for me after that window

## Calling

- Voice calls
- Video calls
- Incoming ringtone
- Permission guidance
- Microphone mute/unmute
- Camera toggle
- Call timer
- Call logs in chat

## Account

- Username authentication
- Display name
- Profile photo
- Logout

## Chat utilities

- Clear chat view
- Conversation backup/export
- Explore Features menu

## Product rules

The client UI should explain destructive actions clearly. Server-side authorization remains the source of truth for message edit/delete rules; client-side timers are only a usability layer.
